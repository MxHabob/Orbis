## About Orbis

Orbis is a highly advanced, enterprise-grade school management platform designed to deliver unparalleled performance and data integrity. Built as a sophisticated monorepo with a focus on Arabic-first education workflows, Orbis provides a comprehensive, unified ecosystem for schools to manage students, grades, attendance, complex scheduling, and financial operations with state-of-the-art technologies.


## Features

**Student Management** — Comprehensive registration, enrollment, and tracking across academic years with support for advanced class divisions, seating allocations, and extensible custom metadata.<br/>
**Advanced Grading & Assessments** — Create dynamic exams, quizzes, assignments, and oral assessments with weighted scoring matrices, grade publishing, and deep analytical per-month tracking.<br/>
**Smart Attendance Tracking** — Granular attendance logging per scheduled lesson with statuses (present, absent, late, excused, sick) supported by real-time teacher verification and automated alerts.<br/>
**Algorithmic Class Scheduling** — Build robust weekly timetables with intelligent time slots, dynamic subject-teacher assignments, and automated conflict detection engines.<br/>
**Complex Academic Structure** — Full control over academic years, terms, multi-tiered grades, and subjects with automatic dependency resolution and fast-track setup.<br/>
**Certificate Designer Studio** — A powerful, Figma-inspired visual editor embedded directly within the platform for designing and generating pixel-perfect student certificates and analytical reports.<br/>
**Secure Document Vault** — Enterprise-grade, S3-backed file storage with hierarchical folders, intelligent pinning, and strict role-based access control for document management.<br/>
**Parent & Guardian Portal** — Seamlessly link parents to students with defined relationship hierarchies, primary contact routing, and comprehensive communication channels.<br/>
**Student Lifecycle Promotions** — Promote, retain, or transfer students between academic years via a robust engine with immutable, full-system audit trails.<br/>
**Real-time Notifications** — Intelligent, event-driven in-app notifications for grade publications, critical attendance drops, system announcements, and behavioral reports.<br/>
**High-Performance Desktop App** — Native, hardware-accelerated desktop application built with Tauri, delivering offline-capable access and superior performance.
