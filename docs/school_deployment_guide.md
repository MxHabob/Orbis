# 🏫 دليل تشغيل نظام Orbis في المدرسة من الصفر (On-Premise Deployment Guide)

يركز هذا الدليل على طريقة تثبيت وتشغيل نظام **Orbis** محلياً بالكامل (Offline) في خادم المدرسة الرئيسي، دون الحاجة لوجود الكود المصدري على جهاز السيرفر، مع الحفاظ على خصوصية البيانات واستقرار النظام 100%.

---

## 🛠️ المتطلبات الأساسية (Prerequisites)

قبل البدء، يجب تجهيز جهاز خادم المدرسة (Server) بالبرامج التالية:

1. **نظام التشغيل**: Windows 10/11 (الإصدارات الاحترافية Pro أو Enterprise يُنصح بها) أو Windows Server.
2. **برنامج Docker Desktop**:
   - قم بتحميل وتثبيت Docker Desktop من الموقع الرسمي: [docker.com/products/docker-desktop](https://www.docker.com/products/docker-desktop/)
   - **تنبيه أثناء التثبيت**: تأكد من تفعيل خيار **WSL 2** (Windows Subsystem for Linux) أو **Hyper-V**.
   - بعد انتهاء التثبيت وإعادة تشغيل الجهاز، افتح برنامج Docker Desktop وتأكد من أنه يعمل باللون الأخضر (Running) في شريط المهام.

---

## 📥 الخطوة 1: نسخ مجلد التوزيع إلى السيرفر

قم بنسخ المجلد المسمى [dist](file:///c:/Users/YZLPN3/Downloads/new/Orbis/dist) بالكامل إلى خادم المدرسة (مثلاً في المسار `C:\Orbis-Server`).
يجب أن يحتوي المجلد على الملفات التالية فقط:
* `docker-compose.yml`: ملف التكوين العام للحاويات.
* `start-school-server.ps1`: سكريبت التشغيل الذكي والتهيئة التلقائية.
* `.env.example`: نموذج لمتغيرات البيئة والسرية.
* `README.md`: الدليل الفني القصير.

---

## 🔑 الخطوة 2: مصادقة سجل الصور (إذا كان سجل الصور خاصاً)

إذا كانت صور حاويات Orbis مرفوعة كحزم خاصة (Private Packages) على حسابك في GitHub، يجب تهيئة صلاحيات السيرفر لسحبها:

1. قم بإنشاء **Personal Access Token (classic)** من حساب مطور Orbis على GitHub بالصلاحية التالية فقط:
   - `read:packages` (لقراءة وتحميل الصور المترجمة).
2. في سيرفر المدرسة، افتح **PowerShell** واكتب الأمر التالي لتسجيل الدخول:
   ```powershell
   docker login ghcr.io -u YOUR_GITHUB_USERNAME
   ```
3. سيطلب منك النظام كلمة المرور، ضع الـ **Token** الذي قمت بإنشائه ككلمة مرور (وليس كلمة مرور الحساب العادية).
   > [!NOTE]
   > إذا كانت الصور عامة (Public Packages)، يمكنك تخطي هذه الخطوة تماماً.

## 🚀 الخطوة 3: التشغيل الذكي (بضغطة زر)

الآن، سنقوم بتهيئة وإطلاق النظام بالكامل بشكل تلقائي وآمن:

1. اضغط على زر ابدأ (Start)، وابحث عن **PowerShell**.
2. انقر بزر الفأرة الأيمن على PowerShell واختر **تشغيل كمسؤول (Run as Administrator)**.
3. انتقل إلى المجلد الذي وضعت فيه الملفات:
   ```powershell
   cd C:\Orbis-Server
   ```
4. نفذ أمر تشغيل السكريبت المرفق لتجاوز سياسة الحماية وتشغيل التهيئة:
   ```powershell
   powershell -ExecutionPolicy Bypass -File start-school-server.ps1
   ```

### 🧠 ماذا سيفعل هذا السكريبت في الخلفية؟
* **توليد مفاتيح تشفير قوية وعشوائية**: ينشئ ملف `.env` آمن ويقوم بتوليد كلمات مرور وتشفير مخصصة ومحمية لجهاز المدرسة.
* **كشف الـ IP المحلي للسيرفر**: يكتشف عنوان الـ IP الداخلي للسيرفر على شبكة المدرسة (مثل `192.168.1.100`) ويقوم بربط التطبيق والـ CORS به تلقائياً.
* **تحميل الصور وتشغيلها**: يسحب صور النظام الثلاث (`api`, `dashboard`, `worker`) من السجل ويشغلها في الخلفية.
* **تهيئة قاعدة البيانات تلقائياً**: يقوم بتشغيل الـ Migrations وبناء الجداول وإدخال البيانات الأساسية (الصفوف والمواد) تلقائياً عند أول إقلاع.

## 📡 الخطوة 4: روابط الوصول والاستخدام

عند انتهاء السكريبت بنجاح، ستظهر لك لوحة التحكم وبيانات الاتصال:

### 1. من جهاز السيرفر نفسه:
* **لوحة التحكم للمدراء والمعلمين (Dashboard)**: [http://localhost:3001](http://localhost:3001)
* **واجهة المبرمجين (API Console)**: [http://localhost:3002](http://localhost:3002)
* **إدارة الملفات المخزنة (RustFS Console)**: [http://localhost:9001](http://localhost:9001)
  *(اسم المستخدم الافتراضي: `rustfsadmin` / كلمة المرور الافتراضية: `rustfs_local_2026`)*

### 2. من أجهزة المدرسة الأخرى (المعلمين، الإداريين) على نفس الشبكة المحلية:
افتح المتصفح من أي جهاز متصل بشبكة الواي فاي أو الكيبل الخاصة بالمدرسة، واكتب الـ IP المحلي الخاص بالسيرفر مع البورت `3001` (سيقوم السكريبت بطباعة الرابط الصحيح لك تلقائياً):
```
http://192.168.1.100:3001
```

## ⚙️ الخطوة 5: الإدارة والتحكم بالخادم مستقبلاً

افتح الـ PowerShell كمسؤول في مجلد التطبيق ونفذ الأوامر التالية لإدارة خادم المدرسة:

### إيقاف السيرفر مؤقتاً:
```powershell
docker compose down
```

### تشغيل السيرفر مجدداً:
```powershell
docker compose up -d
```

### مشاهدة السجلات والـ Logs لمراقبة عمل النظام وحل المشاكل:
```powershell
docker compose logs -f api
```

### تحديث النظام لإصدار جديد ومستقر:
لتحديث السيرفر عند إطلاق إصدار جديد (مثلاً تغيير رقم النسخة في ملف `.env` إلى `v1.1.0`):
```powershell
docker compose pull
docker compose up -d
```

### تصفير وحذف قاعدة البيانات والملفات بالكامل (تنبيه: سيحذف كافة البيانات المدرجة!):
```powershell
docker compose down -v
```

## 🔒 تأمين وحماية خادم المدرسة
* **جدار الحماية (Firewall)**: تأكد من السماح للمنافذ التالية بالاتصال عبر الشبكة المحلية للمدرسة:
  - `3001`: للوصول للوحة التحكم (Dashboard).
  - `3002`: لوجهة الـ API.
* **النسخ الاحتياطي (Backups)**: يتم تخزين بيانات قاعدة البيانات والملفات في مجلدات Docker volumes ثابتة. يُنصح بعمل نسخة احتياطية دورية لمجلد الـ volume الخاص بقاعدة البيانات `orbis_pgdata`.
