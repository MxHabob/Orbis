# Proposal

## Why

يحتاج المدير أو الموظف المخوّل إلى سؤال الوكيل عن الرسوم غير المسددة والحصول على نتيجة قابلة للاستخدام دون انتظار استعلام طويل أو تصدير يدوي. كما تحتاج المدرسة إلى تجهيز رسائل تذكير مناسبة وإرسالها لأولياء الأمور عبر تكاملاتها المرتبطة، مع ضمان ألا تتحول المحادثة إلى وسيلة لتسريب البيانات المالية أو إرسال جماعي غير مقصود.

## What Changes

- إضافة استعلام AI عن الرسوم المستحقة والمتأخرة ضمن صلاحية ونطاق المستخدم، مع عرض النتائج الصغيرة في جدول داخل التطبيق.
- إنشاء تقرير Excel قابل للتنزيل للنتائج الكبيرة؛ يعالج التوليد بالخلفية مع حالة تقدم وإلغاء أو إعادة المحاولة دون تعليق المحادثة أو الواجهة.
- إنشاء مسودة رسالة تذكير قابلة للتحرير، مع اختيار قناة وتكامل مؤسسي نشط يدعمها فعلًا، والتحقق من جهة اتصال ولي الأمر.
- اشتراط معاينة المستلمين والقناة والمزود والنص النهائي وموافقة صريحة مستقلة قبل أي إرسال جماعي، ثم إظهار نجاح/فشل كل مجموعة دون إعادة إرسال مكرر.
- احترام صلاحيات المالية والإشعارات والتصدير، وعدم تمرير صفوف الرسوم أو بيانات الاتصال الكاملة إلى نموذج الذكاء الاصطناعي.

## Capabilities

### New Capabilities

- `secure-ai-finance-reporting`: استعلامات رسوم غير مسددة وعرض النتائج وتصديرها بأمان وباستجابة غير حاجبة.
- `controlled-parent-notifications`: إعداد وإرسال دفعات تذكير أولياء الأمور عبر تكاملات نشطة بعد مراجعة وموافقة نهائية.

### Modified Capabilities

لا توجد مواصفات مؤرشفة سابقة؛ مخزون OpenSpec الحالي لا يحتوي قدرات رئيسية منشورة.

## Impact

- أدوات `AiOrchestrationService` وخدمات الرسوم والطلاب والعلاقات مع أولياء الأمور.
- صلاحيات `FinanceRead` و`ExportData` و`NotificationWrite`، مع تدقيق يربط كل تقرير أو إرسال بالمستخدم والمنظمة.
- محول الإشعارات الموحد: يحتاج إلى دعم اختيار صريح لتكامل متصل ومخوّل للقناة، إذ يختار حاليًا الإعداد الافتراضي ولا يقبل معرف تكامل من المستدعي.
- واجهة AI لعرض جدول صغير، وتنزيل تقرير Excel كبير، واختيار المزود/القناة وتحرير الرسالة ومراجعة الدفعة ومتابعة حالتها.
- مسارات خلفية لتوليد التقارير والإرسال المجدول، مع حدود دفعات ومعدل ومحاولات وتكرار آمن.
