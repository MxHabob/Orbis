# Tasks

## 1. استعلام الرسوم والحدود والصلاحيات

- [ ] 1.1 أضف عقد استعلام الرسوم المستحقة ضمن المؤسسة ونطاق المستخدم، مع تطبيق مرشح الفترة فعليًا وحدّ نتائج واضح؛ تحقق باختبارات صلاحية `finance:read`، وعزل النطاق، ومرشح الفترة، وعدم تسرب تفاصيل عند الرفض.
- [ ] 1.2 أضف شكل استجابة يفصل الملخص عن تفاصيل النتائج: جدول لا يتجاوز 50 صفًا، أو معرّف مهمة فقط لما فوق 50؛ تحقق باختبارات الحدين 50 و51، وأن تفاصيل الصفوف لا تدخل سجل المحادثة أو سياق النموذج.

## 2. تأمين التقارير وتشغيل التصدير بالخلفية

- [ ] 2.1 حوّل توليد التقارير من تنفيذ متزامن داخل طلب HTTP إلى executor/worker فعلي يعيد معرّف المهمة بسرعة ويدعم الحالة والإلغاء والفشل؛ تحقق باختبار يثبت أن الطلب لا ينتظر إنشاء الملف وأن الفشل ظاهر.
- [ ] 2.2 أضف XLSX للرسوم المستحقة إلى worker من بيانات خادمية ضمن النطاق المصرح، وخزنه في مساحة مؤقتة خاصة بمدة صلاحية وتنظيف؛ تحقق باختبارات محتوى الملف، وانتهاء الصلاحية، والتنظيف، وفشل التخزين دون نجاح شكلي أو رجوع لمجلد عام.
- [ ] 2.3 أمّن إنشاء المهمة وحالتها وإلغاءها وتنزيلها بصلاحية `finance:read` و`data:export` والتحقق المتكرر من المنشئ والمؤسسة والنطاق؛ أزل المسار الداخلي من DTO، وأضف اختبارات منع الوصول بين المستخدمين والمؤسسات وبعد انتهاء الصلاحية وفقد الصلاحية.
- [ ] 2.4 وثّق عقد تنزيل التقرير المؤقت وسلوكه عند الانتهاء أو الفشل، وتحقق أن أمثلة الواجهة لا تعرض رابطًا دائمًا أو مسارًا محليًا.

## 3. اختيار تكامل الإشعارات والتحقق منه

- [ ] 3.1 وسّع محول الإشعارات الموحد لقبول معرف التكامل المختار، وحلّه داخل منظمة الطلب والتحقق من التفعيل والقناة والمحول المنفذ والاعتمادات؛ تحقق باختبارات رفض التكامل غير المرتبط أو غير المدعوم وعدم الرجوع الصامت إلى الافتراضي.
- [ ] 3.2 أضف استعلامًا خادميًا للتكاملات المؤهلة وفحص اتصال فعلي حيث يدعمه المحول، وأظهر سبب عدم الأهلية بوضوح؛ تحقق باختبارات مزود سليم وفاشل ومفقود الاعتماد، ووثّق القنوات المدعومة فعليًا.

## 4. معاينة المستلمين والموافقة المرتبطة بها

- [ ] 4.1 أنشئ خدمة إعداد مرشحي أولياء الأمور من الرسوم والعلاقات المسجلة بعد التحقق من `finance:read` و`guardian:read` و`notification:write` ونطاق المستخدم؛ تحقق باختبارات الصلاحيات ووسائل الاتصال غير الصالحة والاستبعادات دون كشف بيانات لغير المخولين.
- [ ] 4.2 أنشئ معاينة محفوظة محدودة الصلاحية تحتوي المستلمين والقناة والتكامل والنص النهائي وبصمة المحتوى، مع بيانات اتصال مقنّعة ورسالة افتراضية لا تكشف مبالغ؛ تحقق باختبارات قوالب الرسائل وتخصيص القيم لكل مستلم وانتهاء المعاينة.
- [ ] 4.3 اربط الموافقة الصريحة بمعاينة غير قابلة للتبديل، وأعد فحص الصلاحيات والتكامل والأرصدة عند الموافقة وأبطل المعاينة عند أي تغيير؛ تحقق باختبارات التعديل والإلغاء وتغير حالة السداد وعدم إنشاء مهمة بلا تأكيد.
- [ ] 4.4 أضف اختبارات وتوثيقًا لمسار المعاينة والموافقة، بما في ذلك الحالات التي تتطلب معاينة جديدة وعدم الإرسال عند غياب التأكيد.

## 5. تنفيذ الإرسال الجماعي وتتبع نتائجه

- [ ] 5.1 أضف سجل مهمة إرسال ونتيجة لكل مستلم مرتبطين بالمنشئ والمؤسسة والموافقة والتكامل، مع حدود الدفعة والتزامن والمعدل وحالات التقدم والإلغاء؛ تحقق باختبارات إنشاء المهمة وعزلها وإيقاف الرسائل التي لم ترسل بعد.
- [ ] 5.2 نفّذ الإرسال عبر خدمة الإشعارات الموحدة بمعرف التكامل الموافق عليه، مع مفاتيح عدم تكرار وإعادة محاولة للفشل الآمن فقط؛ تحقق باختبارات النجاح والفشل الجزئي وإعادة المحاولة والمهلة الملتبسة دون تكرار الإرسال الناجح.
- [ ] 5.3 أضف تدقيقًا لا يسجل أسرار المزود أو بيانات اتصال كاملة، ورسائل خطأ صريحة عند فشل الاتصال أو الإرسال؛ تحقق بمراجعة سجلات الاختبار ونتائج كل مستلم.

## 6. أدوات الوكيل وتجربة المستخدم والتحقق الشامل

- [ ] 6.1 أضف أدوات الوكيل لاستعلام المتأخرين وإعداد مسودة تذكير، مع تحقق صلاحية خادمي مستقل لكل أداة وإرجاع ملخص أو معرّف مهمة فقط إلى النموذج؛ تحقق باختبارات الرفض الافتراضي وعدم إدراج الصفوف المالية أو بيانات الاتصال في transcript.
- [ ] 6.2 أضف واجهة جدول النتائج الصغيرة وتنزيل التقرير ومتابعة الحالة، ثم اختيار القناة والتكامل وتحرير النص ومعاينة المستلمين والتأكيد الصريح ومتابعة الإرسال؛ تحقق باختبارات UI لحد 50/51، والفشل، والإلغاء، وعدم الإرسال قبل الموافقة.
- [ ] 6.3 حدّث الترجمات العربية والإنجليزية ووثائق تشغيل الأدوات والتقارير والتكاملات؛ تحقق بتشغيل `bun run i18n:audit` واختبارات/فحوصات الحزم المتأثرة.
- [ ] 6.4 نفّذ اختبار تكامل شامل من استعلام الرسوم حتى تنزيل التقرير أو إرسال دفعة معتمدة، وتحقق من الصلاحيات والعزل وعدم التكرار وسلوك الفشل دون تعليق الواجهة.
