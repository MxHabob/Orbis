# Spec Delta

## Purpose

تمكّن هذه القدرة المستخدمين المخولين من تحديد الرسوم غير المسددة بوضوح والحصول على النتائج المناسبة لحجمها، مع حماية بيانات الطلاب والرسوم من التسرب إلى سياق النموذج أو جلسة محادثة غير مناسبة.

## ADDED Requirements

### Requirement: الاستعلام عن الرسوم المستحقة
The system MUST يعرض الرسوم غير المسددة أو المتأخرة بعد التحقق من صلاحية القراءة المالية ونطاق المؤسسة والوحدات التنظيمية للمستخدم.

#### Scenario: مستخدم مخول يسأل عن غير المسددين
- **WHEN** يسأل مستخدم يملك صلاحية `finance:read` عن الطلاب ذوي الرسوم غير المسددة
- **THEN** يعيد النظام عدد الطلاب والرسوم المطابقة مع الرصيد المستحق وحالة الرسوم وتاريخ الاستحقاق ضمن نطاقه فقط

#### Scenario: المستخدم لا يملك صلاحية القراءة المالية
- **WHEN** يطلب مستخدم بلا صلاحية `finance:read` قائمة المتأخرين
- **THEN** يرفض النظام الطلب ولا يكشف عددًا أو أسماءً أو مبالغ أو مؤشرات عن نتائج المطابقة

### Requirement: اختيار عرض النتائج بحسب الحجم
The system MUST يعرض النتائج الصغيرة كجدول داخل التطبيق، ويصدر تقريرًا قابلًا للتنزيل للنتائج الأكبر دون إدراج الصفوف المالية التفصيلية في سجل المحادثة المرسل للنموذج.

#### Scenario: عدد الطلاب المطابقين ضمن الحد الصغير
- **WHEN** يكون عدد الطلاب ذوي الرسوم المستحقة 50 أو أقل
- **THEN** يعرض النظام جدولًا مختصرًا للنتائج داخل التطبيق ويمنع إدراج تفاصيل الصفوف الحساسة في تاريخ المحادثة الدائم

#### Scenario: عدد الطلاب المطابقين يتجاوز الحد
- **WHEN** يكون عدد الطلاب ذوي الرسوم المستحقة أكبر من 50
- **THEN** ينشئ النظام مهمة تصدير خلفية لملف Excel آمن التنزيل ويعرض حالة المهمة بدل تحميل جميع الصفوف في رد المحادثة

### Requirement: حماية إنشاء وتنزيل تقرير الرسوم
The system MUST يشترط صلاحية `finance:read` و`data:export` لتوليد التقرير أو تنزيله، ويقيد التقرير بهوية منشئه ومؤسسته ونطاقه ومدة صلاحية محدودة.

#### Scenario: تصدير مصرح به
- **WHEN** يطلب مستخدم يملك صلاحية القراءة والتصدير تقريرًا ضمن نطاقه
- **THEN** ينشئ النظام ملف Excel لا يتجاوز بيانات النطاق المطلوب ويتيحه للمنشئ عبر تنزيل موثق الصلاحية

#### Scenario: صلاحية التصدير مفقودة أو انتهت صلاحية الملف
- **WHEN** لا يملك المستخدم صلاحية `data:export` أو يحاول تنزيل ملف منتهي الصلاحية أو تابعًا لمستخدم آخر
- **THEN** يرفض النظام إنشاء الملف أو تنزيله دون إعادة أي محتوى منه

### Requirement: متابعة مهام التقارير الطويلة
The system MUST ينفذ التقارير الكبيرة خارج طلب المحادثة المتزامن، مع حالة تقدم قابلة للاستعلام وإمكانية إلغاء المهمة وإظهار الفشل صراحةً.

#### Scenario: تقرير يتطلب وقتًا طويلًا
- **WHEN** يبدأ إنشاء تقرير كبير
- **THEN** يعيد النظام معرّف مهمة وحالتها الأولية بسرعة، ويمكن للمستخدم متابعة التقدم أو الإلغاء دون تعليق واجهة المحادثة

#### Scenario: فشل إنشاء التقرير
- **WHEN** يفشل إنشاء الملف أو التخزين
- **THEN** يعرض النظام حالة فشل صريحة ولا يعيد ملفًا فارغًا على أنه تقرير ناجح
