# Tasks

## 1. تأمين تفويض أدوات AI

- [x] 1.1 جرد جميع تعريفات الأدوات وصلاحياتها وتصحيح أي صلاحية غير معروفة أو مفقودة؛ تحقق باختبارات تعداد تغطي كل تعريف وتثبت أن أسماء الصلاحيات تتحول إلى صلاحيات IAM معروفة.
- [x] 1.2 جعل فحص التفويض مركزيًا ومغلقًا افتراضيًا عند عرض الأدوات وتنفيذها، وإعادة الفحص قبل تنفيذ أي إجراء مؤكد؛ تحقق باختبارات تثبت رفض أداة مجهولة الصلاحية أو غير مخولة وعدم استدعاء منطقها.
- [x] 1.3 عزل استدعاءات الأدوات بحسب المؤسسة ونطاق الوحدة، وإضافة اختبارات سلبية لمعرّفات من مؤسسة أخرى أو صف خارج تكليف المعلم، مع توثيق عقد التفويض في توثيق API الداخلي.

## 2. بناء السياق الدراسي الموثوق

- [ ] 2.1 حل تكليفات المعلم والصفوف والمواد من سجلات التكليف والجدول على الخادم؛ تحقق باختبارات اختيار تكليف وحيد، طلب توضيح عند تعدد التكليفات، ورفض معرّفات سياق مزورة من الواجهة.
- [ ] 2.2 حل هوية الطالب المسجل وعلاقته بالفترة والصف والاختبارات القريبة من مصادر النظام الموثوقة؛ تحقق باختبارات عدم الاعتماد على ادعاء المستخدم، والتعامل الآمن مع غياب الربط أو وجود أكثر من مادة اختبار.
- [ ] 2.3 ترشيح أدوات AI وفق الصلاحيات والسياق الموثق دون تخزين سياق صلاحية عابر للمستخدمين؛ تحقق باختبارات أن المستخدمين ذوي الأدوار المختلفة يرون وينفذون الأدوات المناسبة فقط.

## 3. أدوات نواقص مستندات الطلاب

- [ ] 3.1 إضافة أداة فحص ملف طالب تعيد المتطلبات المنطبقة والمفقودة فقط باستخدام خدمة تقييم المتطلبات؛ تحقق باختبارات الشروط المنطبقة وغير المنطبقة ومطابقة أسماء الوثائق العربية والإنجليزية دون محتوى ملف أو رابط تنزيل.
- [ ] 3.2 إضافة بحث مرقم عن الطلاب ذوي النواقص ضمن نطاق مصرح به وبحدود حجم معلومة؛ تحقق باختبارات صفوف متعددة الصفحات وعدم تسرب نتائج خارج المؤسسة أو الوحدة، ووثق شكل نتيجة الأداة.

## 4. أدوات المناهج والمذاكرة والتقييم الشفهي

- [ ] 4.1 بناء استرجاع نصي مقيد لمحتوى المناهج المؤرشفة القابلة لاستخراج النص، مع حفظ مراجع المستندات واستبعاد الملفات غير القابلة للاستخراج أو غير المصرح بها؛ تحقق باختبارات نطاق المؤسسة وحالة PDF النصي والملف الممسوح الذي يجب أن يظهر كغير قابل للبحث، دون إضافة OCR.
- [ ] 4.2 إضافة إجابة عن أسئلة المنهج وخطة مراجعة وأسئلة تدريب تستخدم المقاطع المسترجعة فقط وتعرض مصادرها أو تصرح بعدم كفاية المصدر؛ تحقق باختبارات إجابة مسندة وعدم اختلاق مصدر عند غياب نتائج.
- [ ] 4.3 إضافة أداة مسودة الاختبار الشفهي للمعلم من تكليفه ومادته، بحد أقصى 50 سؤالًا ودون حفظ أو نشر أو تسجيل درجات؛ تحقق باختبارات الحد الأقصى ورفض التنفيذ لمعلم بلا تكليف مناسب.

## 5. توصيل الواجهة والتحقق المتكامل

- [ ] 5.1 عرض مصادر المناهج وملخص نواقص الملفات ومسودات الأسئلة في المحادثة بصياغة واضحة دون روابط أو بيانات محمية غير لازمة؛ تحقق باختبارات/فحوص واجهة لنتيجة كل أداة وحالات عدم وجود مصدر أو صلاحية.
- [ ] 5.2 إضافة اختبارات تكامل تغطي مسار المحادثة الكامل من طلب النموذج إلى أداة مقيدة ثم نتيجة آمنة، بما في ذلك رفض الصلاحية عبر API؛ تحقق بتشغيل اختبارات AI وAPI Rust ذات الصلة.
- [ ] 5.3 قياس تكلفة الاسترجاع وزمن الاستجابة ضمن نتائج وصفحات محدودة، ومنع تحميل كل مستندات أو سجلات المؤسسة؛ تحقق باختبار أداء على بيانات متعددة الصفوف ووثق حدود النتائج وإعداداتها.
