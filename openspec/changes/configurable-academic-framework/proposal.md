# Proposal

## Why

يُعامل مسار النتائج الحالي السنة والفصل والشهر والنتيجة النهائية كنموذج تعليمي شبه ثابت، رغم أن Orbis يخدم مؤسسات تعليمية متعددة. أدى ذلك إلى ربط سياسات الحساب بواجهات وتقارير مدرسية محددة، ويجعل تخصيص الجامعة أو المعهد تغييرًا برمجيًا بدل إعداد مؤسسي قابل للتطور.

## What Changes

- فصل التقويم الأكاديمي عن هيكل الفترات، وعن طرح المقررات والتسجيلات، وعن تعريفات التقييم وإدخال الدرجات.
- تمكين المؤسسة من تعريف تقاويم وفترات هرمية اختيارية، دون اشتراط أشهر أو فصلين أو حتى سنة أكاديمية موحدة.
- ربط عروض المقررات وتسجيلات المتعلمين وسياق التقييم بهويات وعلاقات صريحة، مع دعم الساعات المعتمدة والوحدات والكفاءات عند الحاجة.
- تقديم محرك حساب deterministic ومحدد الأنواع يدعم المقاييس والأوزان والمعادلات والتحويل والتقريب والنجاح والترتيب ومخرجات التجميع المعرفة بسياسة المؤسسة.
- إصدار قواعد الحساب دون تعديل نسخ مستخدمة في نتائج معتمدة؛ حفظ النتائج مع مصدرها وإصدارات القواعد والمدخلات، وإتاحة الاعتماد والتصحيح التاريخي الموثق.
- توفير عقود نتائج دلالية typed قابلة لإعادة الاستخدام بين API وDocForge والتقارير، وفصل تعريف التقرير ومخرجاته عن جداول قاعدة البيانات.
- جعل Bootstrap وOnboarding يقدمان إعدادًا أكاديميًا ابتدائيًا مناسبًا لنوع المؤسسة وقابلًا للتعديل، دون إنشاء بيانات تشغيلية تجريبية أو فرض تهيئة مدرسية.
- **BREAKING**: استبدال الاعتماد الداخلي على مخرجات وتقارير ثابتة من نوع الفصل/السنة بعقود نتائج قابلة للتكوين، مع مسار توافق انتقالي للواجهات الحالية.

## Capabilities

### New Capabilities

- `academic-calendars`: تعريف التقويم الأكاديمي وهياكل الفترات وقواعدها دون افتراض أنواع أو مستويات ثابتة.
- `course-offerings`: تعريف المقررات وعروضها وتسجيلات المتعلمين وربطها بالفترات عند انطباقها.
- `assessment-records`: تعريف مقاييس التقييم وعناصره وتسجيل نتائج المتعلم وعلاقاتها بالتسجيلات والعروض والفترات.
- `academic-calculations`: تعريف إصدارات قواعد الحساب typed وحساب النتائج والتجميعات ومخرجاتها وفق سياسة المؤسسة.
- `academic-results`: حفظ نتائج الحساب واعتمادها ونشرها وتصحيحها تاريخيًا مع سجل منشأ وتدقيق.
- `academic-report-contracts`: تقديم عقود دلالية typed للنتائج والتجميعات تستهلكها واجهات Orbis وDocForge دون ربط بالقواعد أو الجداول.

### Modified Capabilities

لا توجد مواصفات سابقة في المستودع.

## Impact

تتأثر نماذج ومخططات وقواعد البيانات في `orbis-domain` و`orbis-infra`، الخدمات في `orbis-app`، وواجهات `orbis-server` وعقود SDK و`packages/schemas`. كما تتأثر واجهات الأكاديميات والدرجات في Desktop وMobile، و`packages/blueprints`، وBootstrap وOnboarding، وعقود التكامل ومحرك DocForge. يجب أن تبقى ترحيلات SeaORM متوافقة مع SQLite وPostgreSQL، وأن تغطي اختبارات القبول نماذج مدرسة وجامعة ومعهد.
