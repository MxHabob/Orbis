# Orbis v1.1.3

## Summary

This release adds managed Solver downloads and safer desktop updates, refreshes the mobile design system, and improves backward compatibility for API document rendering.

## Desktop

- Solver is now downloaded on demand as a separately signed component instead of being bundled in the installer.
- Desktop updates download and verify before prompting to restart and apply them.
- Added download progress and update status to the desktop interface.

## Mobile

- Unified shared design tokens, layouts, surfaces, and controls for a more consistent mobile experience.
- Improved screen scrolling, safe-area handling, and tab-bar behavior.

## API

- Improved document compatibility by accepting legacy and canonical shape paint fields together while preserving canonical values.

## Build reliability

- Rust builds now continue without the optional compiler cache if its download service is unavailable.

## Known Issues

None known.
