# Orbis v1.2.1

## Summary
This release improves student registration safeguards, expands Arabic and English translations for student management and grading, and includes grading data and grid enhancements.

## Added

- Add a registration setting to prevent duplicate full names during student enrollment, with related admission-policy and student-form checks
- Add Arabic and English translations for student management and grading features
- Add support for multi-level headers (group and sub-headers) in the OrbisGrid component
- Add a `component_code` column to the grades table with updated unique index handling for graded components

## Fixed

- Improve i18n message file parsing to handle UTF-8 BOM markers reliably

## Changed

- Improve code readability and structure in assessment and student services

## Other

- General code structure refactoring for readability and maintainability

## Known Issues

None
