# Orbis v1.0.1

## Summary
This patch release improves report generation and document rendering reliability, including Arabic font fallback and template compatibility.

## Fixed

- Coerce submitted report parameters into the tagged values expected by the report pipeline, including date ranges.
- Improve fallback behavior when requested Arabic fonts are not installed.
- Align QR template defaults with the renderer's supported error-correction values.
- Load the ready-template catalog from the local app origin when no catalog URL is configured.

## Known Issues

No known issues specific to this patch release.
