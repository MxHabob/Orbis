# Orbis v1.1.2

## Summary

This release synchronizes Desktop, API, and mobile to v1.1.2. It also improves grading workflows, strengthens desktop updater release validation, and speeds up CI builds.

## Added

- enhance filter builder with advanced translations and functionality
- implement new grading entry and results review pages (grading)

## Fixed

- synchronize API package versions (release)
- enhance Tauri updater manifest to include release notes validation and update documentation
- update Mulverse API configuration to use repository variables and enhance documentation
- enhance caching for Rust and Bun builds in CI and release workflows
- implement Tauri updater metadata creation and validation in release workflow
- update public key normalization to return base64-encoded format and enhance documentation
- implement migration to merge duplicate student roots and prevent recreation
- refactor class-subject-results layout and error handling for improved readability
- replace floating action bar with SettingsBottomBar for selected students
- improve active cell scrolling behavior and header click handling
- update Tauri updater config path and improve login form validation messages
- add responsive max-width to DialogContent component
- normalize manually supplied release versions (ci)
- scope runner temp path correctly (mobile)
- harden tagged Android release build (mobile)
- resolve Gradle plugins online in CI (mobile)
- disable updater artifact signing (staging)

## Changed

- improve import formatting and replace dialog components with FilterDialogFrame

## Other

- Refactor CI workflows and improve Mulverse API validation
- Refactor code for improved readability and consistency

No new release-specific issues are currently known.
