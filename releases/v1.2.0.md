# Orbis v1.2.0

## Summary
This release improves financial oversight, student operations, database backup controls, and multilingual application labels.

## Added

- Implement bulk transfer functionality for student enrollments
- enhance AI components with internationalization support and UI improvements
- enforce autopilot settings for database backups and streamline UI integration
- Enable autopilot for database backups and update UI labels
- enhance finance overview with branch receivables and currency selection (finance)
- add student fee currency summary functionality and update finance overview with late student tracking
- add JobsBanner component and integrate into app-chrome; remove download-manager component

## Changed

- improve code readability by formatting method calls and simplifying conditions in assessment, employee, and student services
- update CSS units from vh/vw to dvh/dvw for responsive design improvements across multiple components
- remove LicenseBanner component and integrate license alerts into status bar

## Other

- Refactor and clean up code across various components
