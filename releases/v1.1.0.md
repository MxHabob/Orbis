# Orbis v1.1.0

## Summary
This release adds currency management, richer audit history, lesson attendance tracking, and an enrollment certificate report, alongside improvements to assessments and reporting.

## Added

- Manage currencies and their display settings.
- Track attendance at the lesson level.
- Browse entity-specific audit history in a timeline.
- Generate enrollment certificate reports.

## Improved

- Improve assessment, report generation, and document layout handling.
- Improve notification handling and error feedback.
- Simplify action menus and behavior-tracking dialogs.

## Known Issues

No known release-blocking issues.
