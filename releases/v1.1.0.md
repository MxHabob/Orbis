# Orbis v1.1.0

## Summary
This release expands Orbis with currency management, improved academic and exam workflows, lesson attendance, audit history, enrollment certificates, and camera integrations. It also improves document generation and adds local institution discovery.

## Added

- Manage currencies and their symbol display settings.
- Track attendance for individual lessons.
- Browse entity-specific audit history in a timeline.
- Generate enrollment certificate reports.
- Connect supported school cameras, including RTSP and ONVIF devices.
- Discover Orbis institutions available on the local network.
- Configure exam sessions, assign proctors, and improve academic scheduling.

## Improved

- Improve assessment workflows, report rendering, and Arabic font handling in generated documents.
- Improve camera connection handling, authentication, and local video relay behavior.
- Improve desktop performance diagnostics and user preference management.
- Improve API deployment configuration and Android release setup.
- Improve notifications, authentication feedback, and action menu behavior.

## Known Issues

No known release-blocking issues.
