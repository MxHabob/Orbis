# Orbis v1.2.3

## Summary
Improves employee selection and connection setup, with usability refinements across academic, finance, and student workflows.

## Improved

- Employee and teacher selectors now load all matching employees across pages instead of stopping at a fixed result limit.
- Web connection setup now uses API mode and loads the configured server URL; local database setup options remain available in the desktop app.
- Refined side-sheet sizing in academic, finance, student, and school-year forms.
- Improved desktop runtime detection and guarded organization navigation against missing route URLs.

## Known Issues
None reported.
