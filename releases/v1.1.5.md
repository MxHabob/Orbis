# Orbis v1.1.5

## Summary
This release improves finance, academic scheduling, results review, printing, and update reliability across Orbis, and adds three expressive animated avatar moods.

## Added

- Add celebrate, curious, and sleepy avatar expressions with matching animations.

## Fixed

- Calculate finance summary metrics from backend totals rather than the current table page.
- Keep registration settings save state synchronized after a successful save.
- Improve PDF preview and printing reliability.
- Keep results-table scrolling contained and show scheduling fields for the selected run mode.
- Improve Solver connection setup and expose autopilot period-lock execution failures.
- Align the mobile offline banner and institution scanner permission screen with their intended layout and theme.
- Make the desktop changelog scrollable while keeping its scrollbar hidden.

## Known Issues
None known at release preparation.
