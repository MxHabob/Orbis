# Orbis v1.2.5

## Summary
Orbis v1.2.5 aligns the mobile app with the unified Orbis design system and Material 3 ergonomics, fixes NativeWind v4 dark-mode theming, Reanimated v4 expressive animations, keyboard/safe-area handling, and adds headless Linux/Docker identity storage support to `orbis-server`.

## Added

- add avatar engine, mobile home hero component, web components, and translations
- add IAM routes implementation for authentication and role management
- add IAM routes module for authentication and user management
- add student management service and related backend/frontend modules
- add core application features, api clients, and UI modules for web and mobile clients
- add report template API routes and desktop Tauri commands

## Fixed

- align mobile theme/animations and support headless Linux identity in Docker (mobile,api)

## Known Issues
None.
